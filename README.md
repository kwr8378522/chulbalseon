# 출발선 — 대한민국에서 100년

대한민국에서 태어나 100살까지 살아가는 텍스트 기반 인생 시뮬레이션 웹 게임.
주사위로 집안과 능력을 받고, 갈림길마다 "능력치 + 운"으로 성공과 실패가 갈린다.
같은 해에 태어난 친구(동창) 30명도 같은 규칙으로 함께 살아간다.

열아홉 살부터는 한 달씩 시간이 흐른다. 달마다 계절·일상 한 줄이 깔리고, 선택지가 있는 사건은 한 해에 서너 번쯤만 나온다. 행동력은 매달 1씩 쌓이며(최대 3) 자유 행동(소개팅·결정사·데이트·상사에게 잘 보이기·부업·운동·이직·집과 차 알아보기 등)에 쓴다. 오른쪽 패널에서 주식·코인·갭투자·수익형 건물·대출을 직접 굴리고, 연말에는 연봉 협상과 결산·시황 리포트가 나온다. 입시·면접·승진·고백 같은 중요한 판정 앞에서는 미니게임으로 성공 확률을 최대 10%p 올릴 수 있다.

## 실행

- `index.html`을 더블클릭한다. 빌드 도구, 서버, 외부 라이브러리가 필요 없다.
- 진행 상황은 브라우저 localStorage에 달마다 자동 저장된다. (저장 형식이 바뀌어 이전 버전의 저장은 이어할 수 없다.)
- 타이틀에서 "새 인생 시작"을 누르면 이름을 묻고, 이어서 주사위를 굴린다. 타이틀 화면을 한 번 누르면 음악이 시작된다(브라우저 자동재생 제한).
- 시드 입력란은 없앴다. 같은 출발선을 다시 살아 보려면 주소 뒤에 `?seed=ABC123-5-M`을 붙여 연다. 가운데 숫자는 다시 굴린 횟수, 끝의 `M`/`F`는 직접 고른 성별이다(주사위에 맡겼으면 생략). 시드는 설정 창과 엔딩 화면에 표시된다. 미니게임 보너스는 손으로 얻는 값이라 시드만으로는 재현되지 않는다.
- 주사위에서 아주 드물게(0.6%) 재벌가가 나온다.
- 성별은 캐릭터 생성 화면에서 직접 고를 수 있고, 주사위는 횟수 제한 없이 다시 굴릴 수 있다. 횟수를 제한하려면 `data.js`의 `REROLLS`를 0이 아닌 값으로 바꾼다.

## 동작 구조

### 한 해의 흐름
1. `Sim.beginYear` — 플레이어의 한 해를 시작하고 그해의 갈림길을 큐에 쌓는다. 동년배 30명은 이 시점에 자동 선택으로 한 해를 끝까지 보낸다.
2. `Sim.view` / `Sim.choose` — 큐에 쌓인 갈림길을 하나씩 보여 주고 선택을 처리한다.
3. `Sim.closeYear` — 돈, 건강, 행복, 무작위 사건을 정산하고 동년배 소식을 붙여 그해 기록을 확정한다.

### 월 단위 진행 (19세 이상의 플레이어만)
- `Sim.advance`가 다음 달 또는 다음 해로 넘긴다. 유년기와 동년배는 1년 단위 그대로다.
- 분기 말(3·6·9·12월)에 `Sim.mktQ`의 시세가 보유 자산에 반영되고, 작년 저축액의 1/12이 달마다 미리 들어온다(연말 `finance`에서 정산).
- 달마다 하나가 일어난다: 예정된 일·직장·연애 사건(`extras.js`의 `scheduled`, `QX`) → 돌발 사건(`quarter.js`의 `QEV`) → 선택지 없는 소소한 사건(`NEWS`) 또는 계절 한 줄(`text.js`의 `MON`, `extras.js`의 `MONX`). 빈도는 `data.js`의 `QTR.eventP`, `QTR.newsP`와 `QX`의 확률로 조절한다.
- "앞으로 이런 제안은 받지 않는다"를 고른 사건(돈 부탁, 종목 귀띔, 수익 보장, 코인 불장, 동업, 사모펀드)은 `p.fl.mute`에 기록돼 다시 나오지 않는다.
- 자유 행동은 `quarter.js`·`extras.js`의 `A(...)` 목록에 한 줄씩 추가한다. 수치는 `data.js`의 `QTR`, `ASSETS`, `DATE`, `SALARY`, `CARS`, `BLD`.
- 갈림길에 `ok(p, c)`를 달면 그 조건이 깨졌을 때 자동으로 건너뛴다. 결과에 `quiet`를 달면 연출 없이 다음 갈림길로 넘어간다.

### 2차에서 더한 경로
- **고입**: 15세에 입시 학원을 고르고(`EDU.hsPrep`), 중학교 때 다닌 학원(`EDU.tutorBonus`)과 합쳐 특목고·자사고 합격 점수에 더한다. 부모 소득이 감당하는 만큼만 고를 수 있다.
- **마이스터고·특성화고**: 기능반 → 전국기능경기대회 → 메달리스트 대기업 생산직 특별채용. 메달이 없어도 고졸 공채에 지원할 수 있고, 전문대졸의 대기업 생산직 합격률도 올렸다.
- **의대 입시반**: 18세에 부모 재력으로 고르며 의·치·한·약·수 지원 점수에 `EDU.examPrep.med.medBonus`가 붙는다.
- **대학**: 4월 조별 과제와 가을 축제에 CC 기회가 오고, 자유 행동 "미팅·과팅"이 열린다. 연인에게는 호감도(♥)가 있어 데이트 취향 맞히기, 기념일, 다툼, 상대 부모님 인사가 이별 확률과 프로포즈 성공률을 움직인다.
- **직장**: 상사(성향 4종)·동기·후배가 생긴다. "상사에게 잘 보이기", 회식·무리한 지시·가로채인 공·후배의 실수·줄서기 사건이 관계를 바꾸고, 관계는 승진 확률(`H.teamBonus`)과 연말 고과에 반영된다.
- **가업**: 직급(대리~부사장)이 있고, 떠났다 돌아와도 경력과 연봉이 이어진다. 아버지 작고 뒤 대표이사 취임·전문경영인·매각 가운데 고른다.
- **직업군인**: 학군단 복무 뒤 장기복무, 학사장교·부사관 지원. 계급정년이 있고 대령에서 장군 진급 심사를 받는다.
- **연예인**: 외모가 좋으면 17세 길거리 캐스팅, 성인 뒤 오디션. 연습생 → 무명 → 얼굴이 알려진 → 인기 → 톱스타(`CELEB`).
- **결혼정보회사**: 상향혼·동급·하향혼과 중시 조건(외모·경제력·집안·성격·나이)을 고르면 프로필 세 장이 나온다.
- **자녀**: 나이마다 성장 문장이 나오고 어린이날·학예회·사춘기·진로 선택이 자녀와의 사이(`k.rel`)를 바꾼다.
- **부동산·상속**: 집 알아보기에 상급지 갈아타기가 들어갔고, 투자 탭에서 갭투자(지역 5곳 × 아파트·빌라, 8채까지)와 수익형 건물(8채까지)을 바로 사고판다. 상속은 건물·현금·빚으로 구성되며 빚이 더 많으면 한정승인·상속 포기를 고른다.
- **난이도**: 캐릭터 생성 화면에서 축복 모드·쉬움·보통·어려움 네 단계 가운데 고른다. 플레이어에게만 적용되며 판정 확률, 해고율, 승진, 임원 심사 기준을 바꾼다(`data.js`의 `DIFF`). 보정 폭은 선택지마다 "축복 +N%p"처럼 표시된다.
- **월 적립식 자동 매수**: 투자 탭에서 자산마다 월 적립 금액을 정하면 달이 바뀔 때마다 자동으로 산다(`Sim.setDca`).
- **연말 결산 화면**: 해가 바뀔 때 순자산 변화, 최근 12년 추이 그래프, 자산 구성, 살림, 시황을 한 화면으로 보여 준다. 자동 진행 중에도 버튼을 눌러야 다음 해로 넘어가며, 설정에서 끌 수 있다.
- **자동 진행**: 선택지가 나와도 꺼지지 않는다. 동창 모임·청첩장·회식에도 "앞으로 무시" 선택지가 있다.
- **문구**: 소소한 사건은 묶음마다 변형을 여러 개 두고 최근 45건 안에 나온 변형은 피한다(`extras.js`의 `NEWS`, `RECENT`). 계절 문장도 최근에 쓴 것은 피한다. 평일 낮에 자리를 비우는 사건은 직업에 맞는 문구를 쓴다(`workCtx`).
- **개원의**: 개업 초기 고전의 타격을 줄이고, 해마다 평판이 회복되며, 소득 하한을 두었다.
- 회사 이름은 `text.js`의 `CO`, 배경음악 9곡은 `audio.js`의 `MOODS`(영아·유년·청소년·수험·청년·직장·중년·노년·황혼).

### 갈림길
- 각 갈림길은 `Sim.DEC[이름]`에 `build`(선택지 목록)와 `resolve`(결과 처리)로 정의된다.
- 선택지의 `prob`은 화면에 표시되는 성공 확률, `stats`는 영향을 주는 능력치, `dis`는 고를 수 없는 이유다.
- 선택지의 `ai` 값은 동년배와 자동 테스트가 그 선택지를 고르는 가중치다. **직업·학력 분포는 확률(`data.js`)과 이 가중치 양쪽에 영향을 받는다.**

### 판정
- 확률은 평균 능력치(50) 기준값에서 능력치 15점마다 로지스틱 곡선으로 움직인다(`H.pr`).
- 숨은 운은 판정에 최대 ±4%p를 더한다(`D.LUCK_SHIFT`).

### 난수와 재현성
- 세계(거시 경제), 플레이어, 동년배, 소식이 각각 시드에서 파생된 별도 난수 흐름을 쓴다.
- 거시 이벤트와 지역별 집값 흐름은 게임 시작 시 100년 치가 미리 정해진다.
- UI 연출(주사위 숫자 굴림 등)은 `Math.random`을 쓰며 게임 결과에 영향을 주지 않는다.

## 밸런스 조정 방법

수치는 `js/data.js`에 모여 있다. 금액은 만원 단위, 소득은 세전 월소득이다.

| 바꾸고 싶은 것 | `data.js`의 위치 |
|---|---|
| 집안 분위 비율·자산 범위 | `CLASS` |
| 지역별 집값·전세가율·상승률 | `REG` |
| 대출 금리·LTV·DSR | `LOAN` |
| 경제위기·급등기 빈도와 충격 | `MACRO` |
| 세금·연금·생활비 | `TAX`, `PENSION`, `LIVE` |
| 자녀 양육비·사교육비 | `KID` |
| 대학 합격선 | `UNIV`의 `cut` |
| 특목고·자사고 합격선과 효과 | `EDU.high` |
| 고입 학원·의대 입시반·기능경기대회 | `EDU.hsPrep`, `EDU.tutorBonus`, `EDU.examPrep`, `EDU.meister`, `EDU.skillComp` |
| 한 달에 사건이 날 확률, 행동력 | `QTR` |
| 가업 직급·연예인 등급 | `HEIR`, `CELEB` |
| 수익형 건물 | `BLD`, `BLD_LTV`, `BLD_COST` |
| 대학 등급별 취업 확률 | `HIRE` |
| 공무원·전문직 시험 합격률 | `EXAM` |
| 직업별 소득·정년·해고율 | `JOBS` |
| 희망퇴직 압박 확률 | `ERP` |
| 자영업 창업비·폐업률 | `BIZ`, `BIZ_RULE` |
